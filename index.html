Everything as Guitar

演奏台 · 给任何音源装上吉他演奏语义：左手选和弦、右手扫弦（下扫/上扫/哑音）、按住连扫、循环节奏型 —— 扫弦引擎只发标准 MIDI，音源四选一：内置 FM 试听（免真机）/ 导入 .syx / 上传采样（WAV/MP3，单采样变调）/ 外接任何 MIDI 合成器（FM-1 是第一个实测目标）

① 音色 本地选中只影响试听；设备要响同样的音色 → ④「推送到设备」

随附 32 个 CC0 音色 + 2 个原创吉他音色（data/guitar.js，实测数据见 design 字段）；也可载入你自己的 DX7 bank，或上传一个 WAV/MP3 采样（录一个吉他单音，变调出整把「采样吉他」）。

② 和弦垫 · 左手 点垫或按 1–0 选中（选中不发声）；按住垫 = 连续下扫，松手停

③ 右手手势 按钮或键盘 D / U / X，按一次扫一次

扫弦速度 5 ms/弦 （真实扫弦总窗 15–35ms：快扫每弦 2–3ms、慢民谣 6–8ms）
人性化 时机 ± 6 ms 力度 ± 10 vel （固定种子，可复现；关掉 = 完美节拍器）

④ 循环 空格 开/关；换和弦下一小节生效；BPM 用 [ ] 调

节奏型 BPM 100 种子

⑤ 发到设备 Web MIDI · 走 USB；蓝牙 MIDI 见下方说明

MIDI 输入 低音区 C2–A2 = 选和弦（10 槽）｜C4/D4/E4 = 下扫/上扫/哑音
真机三步：① USB 连接，琴上 EDIT → POLY 确认复音、关掉 ARP/SEQ、GLO 查通道 → ② 选音色，点「推送当前音色到设备」（不 SAVE 断电即失，要留就在琴上按住 SAVE）→ ③ 在本页按手势/循环，或用 MIDI 键盘（低音区选和弦、高音区扫弦）。蓝牙：Android Chrome 支持 BLE MIDI；iOS Safari 不支持 Web MIDI，只能本地试听。
⚠ 两条路径都没在真机上验证过：① 演奏用的 MIDI Note On/Off（上游证据只覆盖 SysEx）；② 实时单参数推送/闷音宏（V15，圈内一条实测锚点）。「已发出」≠「已执行」—— 有结果请回来告诉我们。

这一页在做什么（一段话）
左手：和弦垫选中一个和弦（不发声）。右手：手势键把「扫一下」拆成每根弦一个音符的事件序列 —— 起音按拨弦次序错开、力度沿拨弦序递减、人性化给每根弦加固定种子的微小随机。空格开循环后调度器按 BPM 反复排小节，换和弦下一小节生效。本地试听用自带 FM 引擎渲染；发到设备则变成标准 MIDI Note On/Off。「推送当前音色」用 V15 的 155 条实时单参数消息把设备编辑缓冲直接变成所选音色。琴上按键做不到扫弦（ARP 是单音琶音、SEQ 是 16 步录音）—— 扫弦引擎必须住在外部，琴是嗓音。引擎与字节格式来自姊妹项目 fm1-tone-engine（ENGINE-FORK.md 有出处）。
