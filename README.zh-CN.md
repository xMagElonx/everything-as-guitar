# everything-as-guitar

**给任何音源装上吉他演奏语义 —— 浏览器是右手，你的合成器是嗓。** 和弦垫负责"左手按弦"，手势键负责"右手扫弦"（下扫/上扫/闷音 chug），空格开循环节奏型，按住和弦垫就是连扫；每个音色都能被"扫"，不限于吉他音色。扫弦引擎只发标准 MIDI 音符流，音源三选一：**浏览器内置 FM 引擎**（免真机试听）、**自己导入的 `.syx` 音色**、或**外接任何 MIDI 合成器** —— FM-1、Dexed、Volca FM、真 DX7 都行。**M-VAVE FM-1 是第一个实测目标**（本文的硬件章节都是它的事），不是唯一目标。

这是 [fm1-tone-engine](https://github.com/xMagElonx/fm1-tone-engine)（**音色台**：FM/DX7 音色的检索、编辑、写入）的姊妹项目 —— 演奏台。两个项目独立建仓，字节级引擎原样共用（出处见 [`ENGINE-FORK.md`](ENGINE-FORK.md)）。

⚠ **硬件状态 —— 欢迎来测。** 这一页全部能跑、有 **383 项测试断言**罩着，但**面向设备的路径从来没碰过真机**。最大的未知数与全部未验证项见下方清单。

「字节已发出」≠「设备已发声/已执行」。有琴的朋友：USB 连上五分钟，**阴性结果（没反应/不对劲）对我们最有价值** —— 请开 issue。

## 玩法（键盘映射）

| 按键 | 作用 |
|---|---|
| `1`–`0` | 选中和弦（E Em F G C D Dm A Am E7）—— 选中不发声，相当于左手按弦 |
| `D` / `U` / `X` | 手势：下扫 / 上扫 / 闷音 chug（按一次扫一次） |
| `空格` | 循环节奏型开/关（folk 万能 / pop 全交替 / punk 全下刷 / reggae 反拍 / ballad 慢歌，BPM 可调）。全部遵守吉他摆臂法则：下刷落正拍、上刷落反拍（Sukoon Music Academy / GuitarStartGuide / TrueMetronome 三源一致，punk 按真朋克惯例改为八分全下刷） |
| `[` / `]` | BPM −5 / +5 |
| `H` | 人性化开关（每弦 ±6ms 时机、±10 力度抖动，固定种子可复现） |
| **按住和弦垫** | 连扫（motor strum），松手停 |
| **载入采样** | 上传 WAV/MP3 + 定根音 → 变调采样吉他（存 IndexedDB，刷新自动恢复；不可推送设备） |

**MIDI 键盘输入**：低音区 C2–A2（36–45）选和弦槽，高音区 C4/D4/E4 = 下/上/哑 —— 接上 MIDI 键盘就是 VST 播放器的一手姿势。（注意槽位是半音连续映射，G2 选中的是第 8 个垫，不是"G 和弦"。）

## 音源：三种接法（引擎只发 MIDI，谁发声它不管）

1. **浏览器内置 FM 引擎（免真机）**：32 个 CC0 starter 音色 + 2 个原创吉他音色（`data/guitar.js`：AC PLUCK 木吉他拨弦、EL GTR SUS 清音电吉他）。吉他音色是**实测驱动**调出来的：离线渲染量起音时长/亮度衰减曲线（分窗频谱质心）/衰减斜率，迭代到指标达标，测量数据写在音色的 `design` 字段里，`tools/voice_lab.mjs` 可复跑。v2 配方按**雅马哈原厂 GUITAR 1**（ROM1A #12，dx7dump 参数分析；mu:zines「Understanding the DX7」独立印证）的骨架重做：算法 8、反馈 7、比率堆栈 12:3:1、全算子无延音、力度灵敏度（轻扫暗重扫亮——本地试听引擎已支持）、键位缩放、音高包络拨弦瞬态。所有音色都能被扫——**扫弦引擎是音色无关的**，扫 bell 也成立。
2. **导入自己的音色**：自己的 `.syx` bank 随时拖进来（DX7 标准布局），先在内置引擎里扫着听，满意再推给设备；通过权利链审查的外部包可放 `data/external/`（收录标准见 [`docs/voice-sources.md`](docs/voice-sources.md)，缺许可字段的包页面**拒载**并打日志）。
3. **上传采样（WAV/MP3）**：录一个真实吉他单音（或任何声音），拖进来即成一把「采样吉他」。v0.5 起**全自动预处理**：掐头去尾（静音裁剪）→ 峰值归一化 → **根音自动检测**（归一化自相关）→ 可延音素材自动定位**延音循环**（零交叉对齐 + crossfade 回绕）。每个和弦音按变调比率播放（varispeed，**钳制 ±24 半音**只拦极端速率），输出与 FM 路径同构——**包络烘焙进 buffer、永不硬切**，扫弦/循环节奏型/人性化/连扫全部适用。**复杂录音（歌/和声）自动降级**：根音置信不足时不预填、不启用循环（防 glitch 复读），日志提示手动核对根音。采样存在浏览器 IndexedDB 里，刷新自动恢复（隐私模式自动降级为本次会话有效，有日志）。**采样只驱动本地试听与 MIDI out，不能推送到设备**（FM 音源没有采样传输协议）——DSP 与持久化在 `engine/sampler.js`（`FM1_SAMPLER`，纯函数可测）。
4. **外接任何 MIDI 合成器**：MIDI OUT 发的就是标准 Note On/Off 错峰流——FM-1 只是今天测试清单最长的一个；Dexed、Volca FM、真 DX7、任何带 MIDI IN 的音源，接上就是嗓。

## 硬件映射（真琴三步）

1. **一次性设置**：USB-C 连电脑（别走 3.5mm TRS）→ 琴上 EDIT 切 **POLY** → **GLO** 查 MIDI 通道 = 1 → **关掉 ARP 和 SEQ**（防截胡外部 Note）。
2. **让琴变成你选的音色**：页面「推送音色到设备」= 把当前音色的 155 个 VCED 参数逐条实时写入（`engine/params.js` 的 `pushVoice`），立即生效、不用 SAVE；想永久保留在琴上**按住 SAVE**。
3. **演奏**：动作在页面/电脑键盘/MIDI 键盘上（上面的映射表）。分工要说准：**FM 合成引擎跑在琴上，琴不是扬声器**——外面的页面只做一件事，把扫弦手势拆成错峰的 MIDI 音符流喂给它。琴是嗓音，外面才是右手。

## 未验证清单（真机裁判）

- **MIDI Note On/Off 演奏**：上游证据只覆盖 SysEx。FM-1 认不认频道 Note 消息是**最大未知**——页面「发单音」按钮就是第一测。
- **pushVoice 推送**：155 参数全表接受度、是否立即生效、SAVE 持久化规则。
- **复音**：手册称 POLY 最多 12 音（声明非实测）；6 音和弦未验。
- **循环节奏型的 Note 流稳定性**、外部 Note 会不会被开着的 ARP/SEQ 截胡。
- **bank 接收后**：手册说"短暂延迟自动保存" vs 社区实测"要按住 SAVE"——矛盾待裁。
- **FM-1 自己的 27 键键盘**能否经 USB 回传当 MIDI 控制器（成了就能在琴上完成全部操作）。第三方固件已证明这条路硬件上走得通——**CTL-1**（charlesvestal，2026-10 更新：白键=所选音阶、黑键=和弦、旋钮发 CC、自带 GM 音色离机可用；带浏览器模拟器与网页安装器）和 **ETCH** V1.37+（SikkenWorks：开机按住 SEQ 进 MIDI KEYBOARD 模式，27 键全发 USB Note On/Off，F3–G5 八度可移）——但那都是刷机后的行为，**原厂固件**认不认仍未验。
- **不发 Program Change**：认不认 PC 未验证，不臆测。
