# fm1-guitar

**在浏览器里像弹吉他一样弹 M-VAVE FM-1 —— 或者说：给合成器装上吉他的演奏语义。** 和弦垫负责"左手按弦"，手势键负责"右手扫弦"（下扫/上扫/闷音 chug），空格开循环节奏型，按住和弦垫就是连扫；每个音色都能被"扫"，不限于吉他音色。

这是 [fm1-tone-engine](https://github.com/xMagElonx/fm1-tone-engine)（**音色台**：检索、编辑、写入）的姊妹项目 —— 演奏台。两个项目独立建仓，字节级引擎原样共用（出处见 [`ENGINE-FORK.md`](ENGINE-FORK.md)）。

⚠ **硬件状态 —— 欢迎来测。** 这一页全部能跑、有 **279 项测试断言**罩着，但**面向设备的路径从来没碰过真机**。最大的未知数与全部未验证项见下方清单。

「字节已发出」≠「设备已发声/已执行」。有琴的朋友：USB 连上五分钟，**阴性结果（没反应/不对劲）对我们最有价值** —— 请开 issue。

## 玩法（键盘映射）

| 按键 | 作用 |
|---|---|
| `1`–`0` | 选中和弦（E Em F G C D Dm A Am E7）—— 选中不发声，相当于左手按弦 |
| `D` / `U` / `X` | 手势：下扫 / 上扫 / 闷音 chug（按一次扫一次） |
| `空格` | 循环节奏型开/关（folk / folkUp / punk / ballad，BPM 可调） |
| `[` / `]` | BPM −5 / +5 |
| `H` | 人性化开关（每弦 ±6ms 时机、±10 力度抖动，固定种子可复现） |
| **按住和弦垫** | 连扫（motor strum），松手停 |

**MIDI 键盘输入**：低音区 C2–A2（36–45）选和弦槽，高音区 C4/D4/E4 = 下/上/哑 —— 接上 MIDI 键盘就是 VST 播放器的一手姿势。（注意槽位是半音连续映射，G2 选中的是第 8 个垫，不是"G 和弦"。）

## 声音从哪来

- **32 个 CC0 starter 音色** + **2 个原创吉他音色**（`data/guitar.js`：AC PLUCK 木吉他拨弦、EL GTR SUS 清音电吉他）。吉他音色是**实测驱动**调出来的：离线渲染量起音时长/频谱质心/衰减斜率，迭代到指标达标，测量数据写在音色的 `design` 字段里，`tools/voice_lab.mjs` 可复跑。
- 所有音色都能被扫——**扫弦引擎是音色无关的**，扫 bell 也成立。
- 自己的 `.syx` bank 随时拖进来；通过权利链审查的外部包可放 `data/external/`（收录标准见 [`docs/voice-sources.md`](docs/voice-sources.md)，缺许可字段的包页面**拒载**并打日志）。

## 硬件映射（真琴三步）

1. **一次性设置**：USB-C 连电脑（别走 3.5mm TRS）→ 琴上 EDIT 切 **POLY** → **GLO** 查 MIDI 通道 = 1 → **关掉 ARP 和 SEQ**（防截胡外部 Note）。
2. **让琴变成你选的音色**：页面「推送音色到设备」= 把当前音色的 155 个 VCED 参数逐条实时写入（`engine/params.js` 的 `pushVoice`），立即生效、不用 SAVE；想永久保留在琴上**按住 SAVE**。
3. **演奏**：动作在页面/电脑键盘/MIDI 键盘上（上面的映射表），琴只负责发声——它是嗓音，外面才是右手。

## 独立演奏的五条路（不刷机 → 刷机）

| 路线 | 脱离电脑？ | 代价 | 状态 |
|---|---|---|---|
| ① 本页 + 电脑大脑 | ✗ | 零 | **本仓库** |
| ② 手机 + 蓝牙 MIDI（页面自适应，FM-1 自带 BLE；iOS 有 Web MIDI 限制，如实声明） | 兜里揣手机 | 很小 | 本仓库已适配 |
| ③ 原厂 ARP/SEQ 极限压榨 | ✓ | 做不出扫弦（ARP 单音循环、SEQ 手录网格） | 乐器自带 |

| ⑤ 自研固件（Optimist 模块化部件 + Felucca 浏览器模拟器先试；官方更新器可刷回原厂） | ✓ | 数周嵌入式，模拟器全绿前不碰真机 | 远期（见根目录项目计划） |

## 未验证清单（真机裁判）

- **MIDI Note On/Off 演奏**：上游证据只覆盖 SysEx。FM-1 认不认频道 Note 消息是**最大未知**——页面「发单音」按钮就是第一测。
- **pushVoice 推送**：155 参数全表接受度、是否立即生效、SAVE 持久化规则。
- **复音**：手册称 POLY 最多 12 音（声明非实测）；6 音和弦未验。
- **循环节奏型的 Note 流稳定性**、外部 Note 会不会被开着的 ARP/SEQ 截胡。
- **bank 接收后**：手册说"短暂延迟自动保存" vs 社区实测"要按住 SAVE"——矛盾待裁。
- **FM-1 自己的 27 键键盘**能否经 USB 回传当 MIDI 控制器（成了就能在琴上完成全部操作）。
- **不发 Program Change**：认不认 PC 未验证，不臆测。
